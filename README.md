# Memoir '44 Battle Dice Calculator

A small interactive tool for calculating hit probabilities in Memoir '44 combat rolls. Set your dice count, target unit type, current figure strength, and optional special rules (Barrage / Air Power, blocked retreat) to see the full probability breakdown of an attack — including the odds of wiping out the target unit in a single volley.

## Features

- Exact binomial probability distribution across all possible hit outcomes
- Target unit selection (Infantry, Armor, Artillery) with correct hit-face odds per type
- Adjustable current figure strength for weakened (non-full-strength) units
- Toggle: Star counts as a hit (Barrage / Air Power)
- Toggle: No retreat path (Flags convert to hits/figure losses)
- Flag/retreat probability tracked separately
- Single-file, no build step, no dependencies — runs entirely in the browser

## Usage

Open `index.html` in any browser, or visit the hosted GitHub Pages link for this repo. No installation required.
